# Course Requirements & Administrative Rules Breakdown

*Source: Final Project in Internet Application Development - Summer Semester (דרישות פרויקט גמר בקורס פיתוח אפליקציות אינטרנטיות - סמסטר קיץ)*

---

## 1. Administrative Requirements (דרישות מנהליות)

### Team Structure (מבנה הקבוצות)
- Teams of **4 to 5 students**.
- Every student in the team must know the entire codebase thoroughly and be able to answer in-depth technical questions about every single component.
- All team members **must be registered under the same lecturer**. Mixing students across different lecturers is strictly prohibited (results in grade 0).

### Version Control & Git (ניהול גרסאות)
- Mandatory use of Git throughout development from each student's personal computer and personal Git account.
- Must demonstrate standard Git practices: frequent and descriptive commits, feature branching, pull requests, peer reviews, and merges.
- Team must present clear Git documentation showing the exact contributions of each student during the oral defense.
- **Strict Security Warning**: Absolute prohibition against pushing sensitive data (passwords, API keys, session secrets, tokens) to the public Git repository.

### Submission Guidelines (אופן ההגשה)
- Submission deadline: At least 24 hours prior to the oral defense (submission box closes at 23:59 the night before). Late submissions receive a 20-point penalty.
- Submission includes:
  1. Full Project Code ZIP on Moodle.
  2. Direct link in the submission note to the team's public Git repository.
- Each student is tested only once during the oral defense; no retry or resubmission is allowed.

---

## 2. Project Defense & Grading (דרישות ההגנה וקביעת הציון)

- **System Presentation**: The lecturer runs and tests the exact submitted code version for stability, completeness, and functionality. No code modifications are permitted during the defense.
- **Code Knowledge**: The lecturer may question any team member on any line of code, architecture decision, or design pattern across the entire system.
- **Grading Criteria**:
  - Oral defense presentation and answers
  - Code architecture and code quality
  - UI appearance and user experience (UX)
  - System stability and error handling
  - Teamwork and Git contribution evidence
  - Compliance with all technical requirements

---

## 3. Mandatory Documentation (README)
The project root MUST include a comprehensive `README.md` document covering:
1. Installation and execution instructions (including DB setup and seed script).
2. Project structure (explanation of main folders, files, and architectural layers).
3. Short description of core functionalities and implemented features.

---

## 4. Academic Integrity & AI Usage (מקוריות הקוד ושימוש בבינה מלאכותית)
- The code must be original work created solely by the team members.
- AI tools (ChatGPT, Claude, etc.) may be used as development assistants during development, but **every team member must deeply understand every line of code added**. Inability to explain any line of code is treated as lack of project mastery and severely impacts the grade.
